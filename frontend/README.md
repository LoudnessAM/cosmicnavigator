--- Getting Started ---

new device : 
+ install python
+ node.js
+ Git

Installation :
Clone the repo
$git clone https://github.com/LoudnessAM/cosmicnavigator.git

Backend Setup / Activate Virtual Environment
$cd backend
$python3 -m venv venv
$source venv/bin/activate
$pip3 install flask flask-cors
$python3 app.py

Frontend Setup
$cd frontend
$npm install
$npm run dev

Open http://localhost:5173 
should say "Hello, Cosmos!"
